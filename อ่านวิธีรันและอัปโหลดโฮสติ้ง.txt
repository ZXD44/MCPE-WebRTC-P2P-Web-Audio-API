====================================================================
           วิธีรันและอัปโหลด VOICE SERVER ขึ้น WEB HOSTING
====================================================================

[วิธีที่ 1: รันบนเครื่องตัวเอง (Localhost / เครื่องเซิร์ฟเวอร์มายคราฟ)]
1. ดับเบิลคลิกไฟล์ "start_server.bat" ที่อยู่ในโฟลเดอร์นี้
2. หน้าต่างดำจะเปิดขึ้นมา พร้อมข้อความ "SERVER IS RUNNING!"
3. เปิดเบราว์เซอร์เข้าที่: http://localhost:3000


[วิธีที่ 2: นำขึ้น Web Hosting ออนไลน์ 24 ชั่วโมงฟรี (Render.com)]
1. นำโฟลเดอร์นี้อัปโหลดขึ้น GitHub
2. ไปที่ https://render.com สมัครสมาชิกฟรี ➔ กด New + ➔ Web Service
3. ตั้งค่าการ Deploy:
   - Root Directory : server
   - Build Command  : npm install
   - Start Command  : node server.js
   - Plan           : Free ($0)
4. รอประมวลผล 1 นาที จะได้ลิงก์เว็บ HTTPS เช่น https://my-voice.onrender.com
5. ส่งลิงก์นี้ให้ผู้เล่นทุกคนเปิดเข้าใช้งานไมค์ได้ทันที 24 ชม.
